# MVP 명세

> 상태: 확정 · 최종 수정 2026-10-30

## 목표

청도에 처음 오는 사람이 조건 3가지만 고르면, 시간 안에 돌 수 있는 관광 코스를 순서 · 소요 시간과 함께 받아 본다.

## 사용자

- 대구 · 부산 · 울산 등 근교에서 당일치기로 오는 개인 · 커플 · 가족 · 친구
- 청도를 처음 방문하거나 동선을 직접 짜기 귀찮은 사람
- 주 사용 기기: 휴대폰 (모바일 우선으로 확인)

## 기능 목록

| ID | 우선순위 | 기능 | 설명 |
|---|---|---|---|
| F1 | P0 | 조건 선택 | 여행 시간(2 · 4 · 6시간), 동행(혼자 · 커플 · 가족 · 친구), 관심사 태그 다중 선택(1개 이상 필수) |
| F2 | P0 | 코스 추천 | 방문 순서, 장소별 시작 · 종료 시각, 이동 시간, 총 소요 시간, 일치한 관심사 표시 |
| F3 | P0 | 코스 요약 | 총 소요 / 예산, 체류 · 이동 · 여유 시간 막대, 장소 수, 권역 |
| F4 | P0 | 빠진 장소 | 점수는 맞지만 시간이 부족해 빠진 장소 목록 + "6시간으로 다시 만들기" |
| F5 | P0 | 관광지 상세 | 소개, 주소, 운영시간, 휴무, 입장료, 권장 체류, 문의, 방문 팁, 같은 권역 장소, 데이터 출처 |
| F6 | P0 | URL 공유 | 조건이 쿼리스트링에 담겨 같은 링크 = 같은 코스. 링크 복사 버튼 |
| F7 | P0 | 상태 화면 | 로딩(스켈레톤), 빈 결과, 400 잘못된 조건, 404 없는 장소 |
| F8 | P1 | 전체 관광지 목록 | 태그 필터가 있는 목록 |
| F9 | P1 | 장소 빼고 다시 추천 | 결과에서 한 곳을 제외하고 재계산 (`exclude` 파라미터) |
| — | 제외 | LLM, DB, 로그인, 리뷰 · 사진, 지도, 실시간 교통 | 이후 확장 후보 |

관심사 태그: `nature` 자연 · `history` 역사·문화 · `experience` 체험 · `food` 먹거리 · `photo` 사진 명소

## 가정

- 이동 수단은 **자차 기준**. 이동 시간은 권역 단위로 단순화(같은 권역 10분, 다른 권역 25분).
- 출발지는 따로 받지 않고 첫 장소부터 시작한다.
- 운영시간은 표시만 하고, 추천 계산에는 반영하지 않는다 (P1 이후 "지금 운영 중" 배지 검토).

## 완료 기준 (Definition of Done)

- [ ] 배포된 HTTPS URL에서 F1 → F2 → F5 흐름이 동작한다
- [ ] 같은 URL을 다시 열면 같은 코스가 나온다 (결정적 알고리즘)
- [ ] `hours=99` 같은 잘못된 파라미터에 400 응답과 상태 화면이 나온다
- [ ] 없는 장소 id에 404 응답과 상태 화면이 나온다
- [ ] 390px 폭(휴대폰)에서 가로 스크롤 없이 동작한다
- [ ] 키보드만으로 조건 선택과 이동이 가능하다 (버튼 `aria-pressed`, 포커스 표시)
- [ ] 추천 로직 단위 테스트와 API 테스트가 CI에서 통과한다
- [ ] `main`에 push하면 자동 배포된다
