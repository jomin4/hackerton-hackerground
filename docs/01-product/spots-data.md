## 원칙

1. **TourAPI는 조사 도구**다. 수집 원본은 `.data-draft/`(git 제외)에만 두고, 저장소에는 우리가 확인한 사실 · 우리가 쓴 문장 · 우리가 정한 값 · 사진 출처만 넣는다 (한국관광콘텐츠랩 "콘텐츠 캐싱 금지").
2. **확인한 장소만 넣는다.** 모든 장소에 구조화된 `hours`, `checkedAt`(운영시간을 실제로 확인한 날짜), 좌표가 있어야 한다. 확인 못 한 장소는 목록에서 뺀다.
3. **출처 대조 순서**: 장소 공식 홈페이지 → 청도군 문화관광 → TourAPI(한국관광공사). 서로 다르면 앞쪽을 따르고 PR 설명에 차이를 적는다.
4. **소개 · 팁 · 사진 대체 텍스트는 우리 문장**으로 쓴다. TourAPI 소개 글을 옮기지 않는다.
5. **사진은 공공누리 제1유형만**, 원본 URL 그대로, 출처 문구와 함께. 1유형이 없으면 사진 없이(일러스트) 둔다.
6. **"상시 개방" 장소**는 추천 관람 시간(기본 09:00–18:00)을 `hours`에 넣고 `note`에 "상시 개방 · 추천 관람 시간 기준"을 적는다. 해가 진 뒤 볼거리가 있는 곳만 늘린다.
7. **요일 규칙 밖의 휴무**(명절 · 1월 1일 · 월마다 다른 휴무)는 `hours.note`에 우리 문장으로 적는다. 일정 계산은 요일 규칙만 쓴다.
8. `stayMinutes`(권장 체류)와 `tags` · `goodFor`는 우리 판단이므로 PR 설명에 근거를 적는다.

## 결정 · 남은 확인

1. **운문면 식사 (결정 2026-10-31)**: TourAPI 식당 13곳이 모두 청도읍 · 화양읍에 있어, 운문사 앞 "운문토속먹거리촌"에서 식당 2곳(산유화, 툴라운문점) · 카페 1곳(아라오라카페)을 추가했다. 출처는 [청도군 맛나들이 — 운문토속먹거리촌 음식골목내 맛집](https://www.cheongdo.go.kr/food/contents.do?mid=0202110000)(업소명 · 주소 · 전화 · 영업시간 · 대표 메뉴). 대신 청도읍의 오경통닭 옹치기 · 굽은소나무와오리도둑, 화양읍 카페 소우주를 뺐다(개수 범위 유지, 같은 권역에 대안 있음).
   - 이 3곳은 TourAPI에 없어 **좌표가 없다** → Task 4에서 지도 서비스의 주소 검색으로 위경도를 확인해 넣는다.
   - 청도군 페이지에 **휴무일이 없다** → Task 4에서 다른 공개 정보로 확인하고, 확인 못 하면 "매일 영업"으로 넣되 `hours.note`에 "휴무일은 공식 자료에 없음 · 방문 전 확인"을 적는다.
2. **레일바이크 휴무**: "월마다 다름". 요일 규칙으로 넣을 수 없어 `note`로 안내만 한다.
