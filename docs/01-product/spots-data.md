# 관광지 데이터

> 데이터 파일: `apps/api/data/spots.json` · 스키마: [`../03-architecture/data-model.md`](../03-architecture/data-model.md)

## 원칙

1. **출처 우선순위**: 청도군 문화관광 공식 정보 → 한국관광공사(visitkorea) → 각 장소 공식 홈페이지 → 언론 보도
2. 운영시간 · 요금 · 휴무 · 문의는 바뀌므로, 하나라도 넣으면 `checkedAt`(실제로 확인한 날짜)을 반드시 남긴다. 스키마가 이를 검사한다.
3. 확인하지 못한 값은 지어내지 않고 비워 둔다(필드 생략). 화면에는 "방문 전 확인" 안내가 나온다.
   - 운영 정보를 확인하지 못한 장소: `hours` · `closed` · `fee` · `phone` · `checkedAt` 모두 생략
   - 기본 정보(이름 · 주소 · 소개)를 공식 출처로 확인하지 못한 장소: `source`에 `UNVERIFIED_SOURCE`(`"확인 전 임시 정보"`), `address`는 권역 단위까지만 (예: `"경상북도 청도군 청도읍"`)
   - 확인하면 `source`를 실제 출처로 바꾸고, 운영 정보를 넣을 때 `checkedAt`도 함께 넣는다.
4. `stayMinutes`(권장 체류)와 `zone`(권역)은 추천 계산에 쓰이므로 근거를 비고에 적는다.

## 이미지

MVP는 사진 없이 일러스트 · 패턴으로 대체한다. 실제 사진을 넣을 때는 공공누리 표시가 있는 이미지만 사용하고 출처를 표기한다.
