# 화면 구성

> 디자인 원본: claude.ai 디자인 캔버스 "청도 코스 메이커 UI" (아트보드 5개) · 확정 2026-10-29
> 토큰: [`design-tokens.md`](design-tokens.md)

## 공통 레이아웃

- **헤더** (높이 64px, 하단 1px 테두리): 로고(감색 원 + 꼭지) + "청도 코스" / 메뉴 "이용 방법", "관광지" / 검정 버튼 "코스 만들기"(결과 · 상세에서는 "새 코스 만들기")
- **본문 폭**: 최대 1200px, 좌우 여백 24px (모바일 16px)
- **푸터**: 운영 정보 변경 안내 문구 + `© 2026 청도 코스` (모노 글꼴)
- **브레드크럼**: 결과 · 상세 페이지 상단 (`홈 / 추천 코스 / 장소명`)

## 01 홈 `/`

| 영역 | 구성 |
|---|---|
| 히어로 (격자 배경 56px) | 좌: 배지 "청도 여행 코스 플래너", 제목 3줄 "청도 여행, / 세 번만 고르면 / 코스가 됩니다.", 설명, 체크 항목 3개(가입 없이 바로 · 이동 시간 자동 계산 · 링크 하나로 공유) |
| | 우: 조건 카드 — 헤더 "코스 조건 · 3 STEPS" / 01 여행 시간(3칸 그리드, 보조 문구 포함) / 02 누구와 함께(4칸) / 03 관심사(알약 버튼, 다중) / 하단 회색 영역: 선택 요약, 공유 URL 미리보기(`code`), "코스 만들기" 버튼 |
| HOW IT WORKS | 테두리로 이어진 3단 카드 (01 조건 고르기 · 02 잘 맞는 장소 담기 · 03 동선 정리) |
| PLACES | 관광지 카드 6개 (점 패턴 상단에 번호 · 권역 배지, 이름, 요약, 태그, 체류 시간) |
| CTA | "이번 주말 청도, 어디부터 갈까요?" + 버튼 |

상태: 관심사 0개 → 버튼 비활성 "관심사를 하나 이상 골라주세요". 선택된 버튼은 검정 배경 · 흰 글씨, `aria-pressed="true"`.

## 02 코스 결과 `/course`

| 영역 | 구성 |
|---|---|
| 상단 (회색 배경) | 브레드크럼, 제목 "가족과 함께하는 4시간 청도 코스", 조건 칩, 버튼 "조건 수정"(테두리) · "링크 복사"(검정, 클릭 시 "복사됨") |
| 좌: 방문 순서 (가변) | 번호 원 + 세로 연결선 타임라인. 카드: 이름, 권역 배지, 시각 범위(`0:00 – 1:00`), 요약, 일치 태그(감색 연한 배경), 추천 이유, 체류, "상세 보기". 카드 사이 이동 행: 차 아이콘 "차로 약 25분 · 청도읍 → 화양읍" |

## 04 모바일 (390px)

- 헤더 56px, 메뉴는 햄버거 버튼(`aria-label="메뉴 열기"`)
- 결과 상단: 제목 2줄, 조건 칩, 버튼 2칸 그리드
- 요약 카드가 타임라인 **위**로 올라옴
- 타임라인 카드 전체가 상세 링크

## 05 상태 화면

| 상태 | 표시 | 행동 |
|---|---|---|
| 로딩 | 제목 · 칩 · 카드 스켈레톤 + "코스를 계산하고 있어요" (`role="status"`) | — |
| 빈 결과 (200, stops 빈 배열) | 돋보기 아이콘, "조건에 맞는 장소를 찾지 못했어요", 원인 문장 | "N시간으로 늘리기", "관심사 더 고르기" |
| 400 | 경고 아이콘, 문제 값을 강조한 URL 코드, 허용 값 안내 | "조건 다시 고르기" |
| 404 | 모노 글꼴 "404", "찾는 장소가 없어요" | "관광지 목록으로", "홈으로" |

## 접근성 체크

- 모든 선택 버튼은 실제 `<button>` + `aria-pressed`, 그룹은 `<fieldset>` + `<legend>`
- 터치 영역 최소 44px
- 텍스트 대비 4.5:1 이상 (회색 글자는 `#666666` 이상 진하게)
- 아이콘만 있는 버튼은 `aria-label`, 장식 SVG는 `aria-hidden="true"`
- 이모지 사용 안 함, 아이콘은 인라인 SVG(라인 스타일)
