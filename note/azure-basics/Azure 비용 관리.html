비용에 영향을 주는 요인

요인비용을 바꾸는 것예시·주의
리소스 유형리소스 종류, 설정, 배포 지역스토리지: 데이터 종류, 액세스 속도, 백업 복사본 수, 지역. VM: OS·소프트웨어 라이선스, 프로세서 종류·코어 수, 연결 디스크·네트워크 인터페이스
사용량어떤 방식으로 쓰고 지불하나종량제는 청구 주기에 쓴 만큼. 예측 가능하면 예약·절감 플랜, 중단 가능하면 스팟 (02 참고)
유지 관리쓰지 않는데 남아 있는 리소스VM을 만들면 디스크·네트워크 리소스가 함께 생성. VM만 지우면 나머지는 계속 과금

데이터 전송과 청구 영역

청구 영역 ≠ 가용성 영역. 청구 영역은 데이터 전송 요금을 매기려고 지역을 지리적으로 묶은 단위. 데이터 센터 장애 격리 단위인 가용성 영역과 이름만 비슷함.
VM만 지우면 끝이 아님. 함께 만들어진 디스크·네트워크 리소스가 남아 계속 청구됨. 관련 리소스를 하나의 리소스 그룹에 묶어 두면 그룹째 정리하기 쉬움.

가격 옵션 고르기

옵션약정유연성적합한 워크로드예시
종량제없음가장 높음새롭거나 사용량이 들쭉날쭉막 시작한 서비스
예약특정 리소스 용량, 1년 또는 3년낮음오래 켜 두는 예측 가능한 워크로드24시간 운영 프로덕션 SQL
컴퓨팅용 절감 플랜시간당 사용 금액, 1년 또는 3년중간 (VM 패밀리에 묶이지 않음)사용량은 안정, 크기·지역·서비스는 바뀜웹·API 혼합 워크로드
스팟 VM없음회수될 수 있음중단돼도 다시 실행 가능배치 렌더링, 테스트 작업
한 번 고르고 끝이 아님. 주기적으로 다시 검토. 스팟으로 돌리던 작업이 중요해지면 예측 가능한 모델로, 종량제로 쓰던 워크로드가 안정되면 약정 옵션으로 옮김.

04

Cost Management와 태그

Microsoft Cost Management

기능하는 일세부
비용 분석지출을 시각화청구 주기·지역·리소스별 보기, 구독·리소스 그룹·서비스별 집계, 추세, 월·분기·연 예측. 배포 후 급증, 놀고 있는 비프로덕션 리소스 찾기
예산지출 한도 설정구독, 리소스 그룹, 서비스 종류 등으로 범위 지정. 예산을 만들면 예산 경고가 함께 설정됨. 자동화로 리소스 중지·변경 가능
비용 경고한곳에서 경고 확인예산 경고, 크레딧 경고, 부서 지출 할당량 경고
경고 종류대상 고객발생 조건받는 사람
예산 경고모든 고객지출이 설정한 임계값에 도달·초과. Portal 또는 Consumption API로 생성설정한 수신자 (이메일)
크레딧 경고기업계약(EA)만Azure 선불(이전 명칭 금액 약정) 크레딧의 90%, 100% 소진 시 자동계정 소유자
부서 지출 할당량 경고기업계약(EA)만부서 지출이 정한 할당량 임계값(예: 50%, 75%) 도달부서 소유자
예산은 기본적으로 알림. 예산을 만들었다고 지출이 자동으로 막히지 않음. 멈추게 하려면 경고에 자동화를 연결해야 함.

태그

용도태그로 하는 일
리소스 관리특정 워크로드·환경·부서의 리소스를 찾고 조치
비용 관리·최적화비용 보고, 비용 센터별 집계, 예산 추적, 예측
운영 관리업무 중요도·SLA로 리소스 그룹화
보안공개·기밀 같은 데이터 분류 표시
거버넌스·규정 준수ISO 27001 같은 요구 사항 대상 표시, 소유자·부서 태그 필수화
워크로드 최적화·자동화Azure DevOps 같은 자동화 도구가 관련 리소스 식별
예시 태그 이름값 예시쓰임
AppNameShop어느 애플리케이션 소속인가

Owner담당자 이름누구에게 묻나
EnvironmentProd, Dev, Test어떤 환경인가
ImpactMission-critical, High impact, Low impact업무 중요도. 태그가 없으면 핵심 업무용이 아닌 것으로 간주
항목내용
형태이름·값 쌍의 메타데이터, 리소스마다 하나 이상
관리 도구Portal, PowerShell, Azure CLI, ARM 템플릿, REST API
강제Azure Policy로 생성 시 필수 태그 요구, 지워진 태그 다시 적용
상속구독·리소스 그룹의 태그를 리소스가 상속하지 않음
범위모든 리소스에 모든 태그가 필요하지는 않음
태그는 상속되지 않음. RBAC 권한과 Azure Policy는 위에서 아래로 상속되지만 태그는 아님. 리소스 그룹에 붙인 CostCenter로 리소스 비용을 나누려면 리소스에도 같은 태그가 있어야 함.
