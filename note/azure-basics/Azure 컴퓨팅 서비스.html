가상 머신

항목내용
정의IaaS 형태의 가상 서버. 물리 서버처럼 OS와 소프트웨어를 직접 제어
책임하드웨어는 Azure, VM 안의 패치·업데이트·구성은 사용자
쓰는 때OS 완전 제어, 사용자 지정 소프트웨어, 사용자 지정 호스팅 구성
빠른 배포OS·웹 호스팅 구성이 담긴 미리 빌드된 이미지 사용
생성 시 선택크기(vCPU·RAM), 스토리지 디스크(HDD·SSD), 네트워킹(VNet·공용 IP·포트)
사용 사례핵심

클라우드 앱 호스팅수요에 따라 확장·축소
데이터 센터 확장온프레미스 네트워크를 Azure 가상 네트워크로
재해 복구주 사이트 장애 시 Azure로 장애 조치

VM 여러 대 묶기

옵션목적보호 범위비용
확장 집합동일 VM을 부하 분산하며 수요·일정에 따라 대수 자동 조절, 구성 일관성 중앙 관리장애가 아닌 수요 대응VM 요금
가용성 집합VM을 장애 도메인·업데이트 도메인에 분산랙 장애, 유지 관리 재부팅 (데이터 센터 안)추가 비용 없음
가용성 영역VM을 영역에 나눠 배치데이터 센터(영역) 장애 (지역 안)VM 요금 + 영역 간 전송
도메인묶는 기준막아주는 것
장애 도메인전원·네트워크 같은 장애 지점을 공유하는 VM랙 하나의 하드웨어 장애
업데이트 도메인계획된 유지 관리 때 함께 재부팅될 수 있는 VM업데이트로 인한 동시 중단
참고. AZ 지원 지역에서는 영역 기반 설계가 더 넓은 장애 격리를 주어 보통 선호됨.

가벼운 컴퓨팅

Azure Virtual Desktop

항목내용
정의데스크톱·앱 가상화 서비스. Windows 데스크톱과 앱이 클라우드에 있고 여러 기기·위치에서 접속
ID 통합Microsoft Entra ID로 ID·접근 제어
보안앱과 데이터가 Azure 세션에 남아 로컬 기기 노출 감소
세션단일 세션과 다중 세션 Windows 모두 지원
어울리는 대상분산 직원, 계약자, 하이브리드 근무자, 표준 환경이 필요한 팀

컨테이너

구분가상 머신컨테이너
OSVM마다 하나씩호스트 OS 공유, 별도 OS 관리 없음
무게무거움가벼움, 빠르게 생성·확장·중지
장애 후재부팅 필요빠르게 재시작
대표 엔진하이퍼바이저Docker
서비스역할특징요금 참고
Container Instances컨테이너를 가장 빠르고 간단하게 실행PaaS, VM 관리 불필요무료 제공량 없음, 초 단위 과금
Container Apps앱 중심 컨테이너 운영PaaS, 부하 분산·자동 확장 내장월 무료 제공량, 0개로 줄이면 사용 요금 없음
Kubernetes Service컨테이너 오케스트레이션수명 주기·플릿 관리Free 계층은 관리 무료, 노드(VM)는 유료
마이크로서비스. 프런트엔드·백엔드·스토리지를 컨테이너로 쪼개면 백엔드만 따로 확장하는 등 구성 요소별로 독립 유지 관리·확장·업데이트.

Azure Functions

항목내용
정의이벤트 기반 서버리스 컴퓨팅. 인프라가 아닌 코드에 집중
트리거REST 요청, 타이머, 다른 Azure 서비스의 메시지
적합한 작업몇 초 안에 끝나는 작업, 수요가 들쭉날쭉한 워크로드
확장수요에 따라 자동
과금실행 중 사용한 CPU 시간만. 끝나면 리소스 자동 반납
배포 유연성필요하면 비서버리스 환경에 배포해 확장 직접 관리, VNet 안 실행, 완전 격리
상태 모델기본 여부동작
상태 비저장기본값이벤트마다 새로 시작, 이전 실행을 기억하지 않음
상태 저장Durable Functions런타임이 함수 사이에 컨텍스트를 넘겨 이전 작업 추적
