01

Azure Advisor

배포된 Azure 리소스를 평가해 모범 사례 기반의 맞춤형 권장 사항을 준다.

다섯 범주

범주목적
안정성 (Reliability)업무상 중요한 애플리케이션의 연속성을 보장하고 개선
보안 (Security)보안 침해로 이어질 수 있는 위협과 취약성 탐지
성능 (Performance)애플리케이션 속도 개선
운영 우수성 (Operational Excellence)프로세스·워크플로 효율, 리소스 관리 용이성, 배포 모범 사례
비용 (Cost)전체 Azure 지출을 최적화하고 줄임

사용 방식

항목내용
위치Azure Portal에 내장
대시보드모든 구독의 권장 사항을 한 화면에서. 구독·리소스 그룹·서비스로 필터
조치권장 사항마다 즉시 실행, 연기, 해제 중 선택
알림새 권장 사항이 생기면 알림을 받도록 설정
함정 Advisor는 "이렇게 하면 좋다"는 권장 사항이다. 규칙을 만들어 강제하는 것은 Azure Policy.

AzureAWS차이

안정성내결함성 (Fault tolerance)이름만 다름, 둘 다 복원력
보안 · 성능 · 운영 우수성 · 비용보안 · 성능 · 운영 우수성 · 비용 최적화대응 동일
해당 범주 없음서비스 한도 (Service limits)계정 할당량 근접 여부를 보는 AWS 고유 범주

02

Azure Service Health

Azure 자체와 내가 실행하는 리소스의 상태를 알려준다. 전 세계 → 내 서비스 → 리소스 하나로 범위가 좁아지는 세 가지 보기.

세 가지 보기 비교

항목Azure 상태서비스 상태리소스 상태
범위전 세계 모든 서비스·지역내가 사용하는 서비스·지역개별 리소스 (예: VM 한 대)
로그인필요 없음로그인 상태라 내 서비스를 앎내 리소스 기준
보여 주는 것Azure 전반의 상태서비스 중단, 계획된 유지 관리, 상태 권고정상 여부, 원인이 Azure 측인지 사용자 측인지
이럴 때대규모 장애 소식을 들었을 때내 환경에 영향 있는 이벤트 확인, 알림 구성특정 리소스 문제 진단

공통 기능

기능내용
알림서비스 상태에서 구성해 영향 있는 이벤트를 자동 통지
과거 기록지난 알림을 보관해 반복되는 추세 파악
지원 링크워크로드에 영향이 있을 때 지원으로 바로 연결해 빠르게 대응
함정 "로그인 없이 보는 전 세계 상태"는 Azure 상태, "내 구독에 영향 있는 이벤트"는 서비스 상태. 둘을 섞어 묻는 경우가 많다.

AWS비교

AzureAWS차이
Azure 상태AWS Health Dashboard – Service health둘 다 로그인 없이 공개
서비스 상태AWS Health Dashboard – Your account health둘 다 로그인 후 내 계정에 영향 있는 이벤트
리소스 상태계정 이벤트의 영향받는 리소스Azure는 리소스 하나를 위한 상태 보기가 따로 있음
Service Health 알림AWS Health 이벤트 + Amazon EventBridgeAWS는 EventBridge 규칙으로 통지·자동화

03

Azure Monitor

리소스의 데이터를 수집하고, 분석하고, 시각화하고, 결과에 따라 대응하는 플랫폼. Azure뿐 아니라 온프레미스와 다른 클라우드 리소스도 모니터링한다.

구성 요소

구성 요소역할알아둘 점
Azure Monitor수집·분석·시각화·대응 플랫폼 전체Azure, 온프레미스, 다른 클라우드의 VM까지
Log AnalyticsPortal에서 로그 쿼리를 작성·실행간단한 쿼리부터 고급 분석까지, 결과를 추세로 시각화
Azure Monitor 경고조건이 충족되면 자동 통지·조치경고 규칙 + 작업 그룹. 심각도별로 묶어 표시
Application Insights웹 애플리케이션 성능·사용 모니터링Azure, 온프레미스, 다른 클라우드에서 실행되는 앱 모두

경고와 작업 그룹

경고 유형감시 대상예
메트릭 경고메트릭이 임계값을 넘을 때VM CPU 사용률이 80% 이상이면 이메일
로그 경고로그에 특정 이벤트가 나타날 때, 여러 리소스에 걸쳐 가능여러 VM 로그에서 같은 오류가 발생하면 알림

Application Insights

항목내용
대상Azure, 온프레미스, 다른 클라우드에서 실행되는 웹 애플리케이션
설정 방법앱에 SDK 설치, 또는 에이전트로 코드 변경 없이
요청요청 속도, 응답 시간, 실패율
종속성외부 서비스 호출의 속도, 응답 시간, 실패율
사용자 측페이지 뷰와 로드 성능, 사용자·세션 수
서버Windows·Linux 서버의 CPU, 메모리, 네트워크 사용량
가용성 테스트주기적으로 합성 요청을 보내 활동이 적을 때도 앱 상태 확인
함정 Azure Monitor가 전체 플랫폼이고 Log Analytics, 경고, Application Insights는 그 안의 기능. Application Insights는 Azure에 호스팅된 앱만 보는 게 아니다.
