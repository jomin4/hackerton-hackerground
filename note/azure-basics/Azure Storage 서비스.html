계정과 중복성

스토리지 계정

항목내용

접근HTTP·HTTPS로 전 세계 어디서나

보조 지역 규칙

항목내용
주 지역 복제어떤 옵션이든 주 지역 안에서 최소 3벌
보조 지역 선택사용자가 고르지 않음. 지역 쌍에 따라 Azure가 자동 지정
보조 지역 읽기GRS·GZRS는 장애 조치 전 읽기 불가 · RA-GRS·RA-GZRS는 읽기 가능 (최신이 아닐 수 있음)
장애 조치주 지역을 쓸 수 없을 때 보조 지역을 새 주 지역으로 전환
RPO주 지역의 최신 쓰기와 보조 지역의 마지막 쓰기 사이 시간 차. 보통 15분 미만, 보조 복제 시간 SLA는 없음

요구 사항별 선택

요구 사항옵션
비용이 최우선인 개발·테스트 데이터LRS
같은 지역 안에서 영역 장애에도 계속 사용, 데이터를 한 국가 안에 유지ZRS
지역 재해 대비, 보조 읽기는 불필요GRS
지역 재해 대비 + 장애 조치 전 보조 읽기RA-GRS · RA-GZRS
최고 수준의 내구성·가용성·재해 복구GZRS (RA-GZRS)
기억법. Z = 영역(지역 안), G = 다른 지역. GZRS = 영역 + 다른 지역.

서비스와 계층

서비스별 정리

서비스정의주요 용도알아둘 점
Blob비정형 데이터용 개체 스토리지이미지·문서 직접 제공, 동영상·오디오 스트리밍, 백업·재해 복구·아카이브, 분석용 저장URL·REST API·CLI·클라이언트 라이브러리로 접근, Data Lake Storage Gen2의 기반
Files완전 관리형 파일 공유기존 파일 공유 앱을 그대로 클라우드로SMB(Windows·Linux·macOS), NFS(Linux·macOS), 파일 동기화로 Windows Server에 캐시
Queues메시지 저장소비동기 처리, 백그라운드 작업 트리거메시지 최대 64KB, 수백만 개 저장, Functions와 자주 조합
DisksVM용 블록 수준 볼륨 (관리 디스크)VM의 OS·데이터 디스크가상화와 관리는 Azure가 담당
TablesNoSQL 테이블 스토리지대량의 구조적 비관계형 데이터클라우드·하이브리드에서 인증된 호출로 접근

이점내용

보안저장되는 모든 데이터를 암호화, 접근 권한을 세밀하게 제어

관리 편의성하드웨어 유지 관리·업데이트·장애 처리는 Azure가 담당

데이터 옮기기

마이그레이션

구분Azure MigrateAzure Data Box
방식온라인, 실시간물리 장치, 오프라인
역할온프레미스 → Azure 이전을 시작·실행·추적하는 허브대용량 데이터를 장치에 담아 운송
구성·사양검색 및 평가, 서버 마이그레이션, DB·웹앱 도구, ISV 제품 통합장치당 최대 80TB, 견고한 케이스
적합한 상황인프라·앱·데이터의 단계적 이전대역폭 부족, 수십 TB 이상, 일회성·주기적 대량 업로드, 대용량 내보내기
관리 위치Azure Migrate 허브Portal의 Data Box 서비스
보안—작업 후 디스크를 NIST 800-88r1로 초기화

Data Box 진행 순서

단계작업
1. 주문Azure Portal에서 가져오기(import) 또는 내보내기(export) 선택
2. 설정장치를 받아 로컬 웹 UI로 설정하고 네트워크에 연결
3. 복사로컬 데이터를 장치에 복사
4. 반송장치를 Microsoft로 반송
5. 업로드가져오기는 도착 즉시 Azure에 자동 업로드, Portal에서 전 과정 추적
6. 초기화가져오기 완료 후 또는 내보내기 장치 회수 후 디스크를 NIST 800-88r1로 삭제

파일 이동 도구

도구형태방향하는 일고르는 때
AzCopy명령줄 유틸리티한 방향업로드·다운로드, 계정 간 복사, 동기화, 다른 클라우드에서 이동스크립트·자동화
Storage ExplorerGUI 앱 (Windows·macOS·Linux)내부적으로 AzCopy업로드·다운로드, 계정 간 이동마우스로 탐색·관리
Azure 파일 동기화Windows Server에 설치양방향Azure Files와 자동 동기화, 클라우드 계층화, 캐시 여러 개, 고장 서버 교체온프레미스 파일 서버를 Azure와 계속 맞춰 둘 때
클라우드 계층화. 자주 쓰는 파일은 로컬에 복제하고, 덜 쓰는 파일은 요청이 올 때까지 클라우드에만 둠. Windows 파일 서버를 작은 CDN처럼 만드는 원리.
